# Student Portal

## 1. Project Description

Student Portal is a Software Project developed as part of the Git Lab Activity.
The project demonstrates basic student-related functionality while practicing Git
and GitHub version control operations.

## 2. Prerequisites

Before running the project, make sure the following are installed:

- Git
- A C++ compiler such as g++
- A code editor such as Text Editor or Note Pad or Vs Code

## 3. Make the Repository and Push it to Github

Make the repository using: mkdir 2026202015_a1

change directory : cd 2026202015_a1

Initialize the git using : git init 

Define .gitignore file using : touch .gitignore

Create a repository on Github.

Push the local repository to Github

## 4. Project Structure

The project is organized as follows:

## 5. Build the Project

For the C++ source code, compile the program using:

g++ main.cpp

## 6. Run the Project

Run the compiled program using:

./a.out

## 7. Git Workflow

The project uses Git for version control.

Basic workflow:

git status
git add .
git commit -m "commit message"
git push origin main

Feature development is performed using separate branches and merged into
the main branch after completion.

## 8. Branches

The project uses feature branches for different functionality:

- feature-core
- feature/login
- feature/profile
- feature/dashboard
- feature/settings
